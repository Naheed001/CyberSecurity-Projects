# End-to-End SOC Investigation

## Overview

This project simulates a full Security Operations Centre (SOC) investigation workflow from initial alert triage through to incident closure. It covers alert ingestion, log correlation, threat hunting, root cause analysis, and incident response documentation — replicating the end-to-end process a Tier 1/Tier 2 SOC analyst would follow in a real environment.

The fundamentals act as a learning methodology that teaches you the core knowledge required to complete the project in your own time. The write-up is my personal documentation of the lab I carried out.

> **Note:** The fundamentals section was AI-assisted and used as a structured learning resource prior to completing the lab.

## What I Learned

Through this project, I developed a comprehensive understanding of the full SOC investigation lifecycle. I gained hands-on experience triaging alerts in a SIEM, correlating events across multiple log sources, performing threat hunting using IOCs, and producing structured incident reports. This project deepened my understanding of attacker TTPs through the MITRE ATT&CK framework and reinforced the importance of structured, evidence-based analysis in a SOC environment.
