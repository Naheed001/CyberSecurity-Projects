# SSH Brute Force Detection

## Overview

This project covers detection and analysis of SSH brute force attacks. It then builds a Splunk dashboard with threshold-based alerts to detect unauthorised logins (brute force attacks).

## What I Learned

Through this project I have understood how brute force attacks work at an application level and how to make use of Splunk to build threshold-based alerts.

## Tools Used

- Splunk
- Hydra
- Oracle VirtualBox
- Kali Linux
- Ubuntu
